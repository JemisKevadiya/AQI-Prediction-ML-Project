# AQI-Prediction-ML-Project
Air Quality Index (AQI) prediction project using Exploratory Data Analysis, Feature Engineering, and Machine Learning to analyze air pollution trends and forecast AQI levels.

# AQI Prediction using Machine Learning

## 📌 Project Overview
This project predicts Air Quality Index (AQI) using historical air pollution data.
It includes EDA, Feature Engineering, and ML models.

## 📊 Dataset
- Source: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india
- Features: PM2.5, PM10, NO2, SO2, CO, O3, etc.

## 🔍 Exploratory Data Analysis
- Missing value analysis
- Distribution plots
- Correlation heatmap
- Seasonal AQI trends

## ⚙ Feature Engineering
- Date extraction (Year, Month, Day)
- AQI bucket encoding
- Outlier handling
- Scaling

## 🤖 Machine Learning Models
- Linear Regression
- Random Forest

## 📈 Results
- Best Model: Random Forest
- R² Score: 73%

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-Learn

## 📌 Conclusion
The model successfully predicts AQI and provides insights useful for environmental monitoring.
